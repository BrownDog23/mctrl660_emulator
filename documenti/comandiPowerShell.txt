25) Creare un certificato di sicurezza CON OPENSSL

26) Creare un certificato di sicurezza SENZA OPENSSL
STEP 1 — Creare certificato self-signed nello store Windows

Apri PowerShell come Amministratore e lancia:

$cert = New-SelfSignedCertificate `
  -DnsName "192.168.0.10" `
  -CertStoreLocation "cert:\LocalMachine\My" `
  -KeyAlgorithm RSA `
  -KeyLength 2048 `
  -NotAfter (Get-Date).AddYears(10)

Questo crea un certificato valido 10 anni.

54) Assegnare un IP statico PERMANENTE a Rasperry
STEP 1 — Verifica se stai usando NetworkManager

Sul Raspberry:
nmcli device status
Se vedi eth0 con stato connected → stai usando NetworkManager (molto probabile).

METODO CONSIGLIATO (NetworkManager – moderno)
1️_Mostra la connessione attiva
nmcli connection show

Vedrai qualcosa tipo:
Wired connection 1
Prendiamo esattamente quel nome.

2_Imposta IP statico
Sostituisci "Wired connection 1" con il nome reale:
sudo nmcli connection modify "Wired connection 1" \
  ipv4.method manual \
  ipv4.addresses 192.168.0.11/24 \
  ipv4.gateway "" \
  ipv4.dns ""

3️_Riattiva la connessione
sudo nmcli connection down "Wired connection 1"
sudo nmcli connection up "Wired connection 1"

4_Verifica
ip addr show eth0
Deve mostrare:
inet 192.168.0.11/24


5️_Test finale
Riavvia il Raspberry:
sudo reboot

Dopo riavvio:
ping 192.168.0.11
ssh tuo_utente@192.168.0.11
Se funziona → IP statico permanente correttamente configurato.
